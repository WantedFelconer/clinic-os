// ===== REQUEST FLOW =====

HTTP Request
  |
  V
Security Middleware (helmet -> cors -> rateLimit -> body parser)
  |
  V
AuthMiddleware.authenticate() [JWT verification -> req.user]
  |
  V
RBACMiddleware.authorize(roles) [role check]
  |
  V
RBACMiddleware.clinicAccess() [staff membership check]
  |
  V
Route -> Controller.method(req, res)
  |
  V
Model.method() [DAO - mysql2 query]
  |
  V
ErrorHandler.handleError(err, req, res, next) [MySQL error mapping]
  |
  V
JSON Response


// ===== KEY ARCHITECTURAL NOTES =====

1. All server "models" are Plain Old JavaScript Objects (POJOs),
   not ES6 classes or ORM entities.

2. No TypeScript interfaces or classes on the server - all plain JS.

3. Client has no page router - App.tsx (~3167 lines) renders
   all views conditionally with inline mock data.

4. Multi-tenant: all resources scoped under /api/clinics/:clinicId/*

5. UUID v4 for all primary keys across all tables.

6. Soft deletes via is_active boolean on User, Clinic, Patient,
   Prescription, PrescriptionItem, etc.

7. JWT authentication + role-based authorization (patient, doctor,
   assistant, admin) + clinic staff membership validation.

8. Database: 19 tables with CHECK constraints, foreign keys,
   and composite unique keys enforcing domain rules.
